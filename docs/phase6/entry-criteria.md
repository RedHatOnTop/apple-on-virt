# Phase 6 Entry Criteria (Gate)

Phase 6 is OPTIONAL. It is allowed only if all criteria below are satisfied.

## Admission checklist (ALL MUST BE TRUE)

- [ ] Phase 5g verdict exists and is committed
- [ ] Kernel code execution has been observed
- [ ] Failures are deterministic and OS-internal
- [ ] No missing hardware access is observed
- [ ] Emulator identity is documented and locked
- [ ] Project success criteria are redefined beyond Phase 5
- [ ] Willingness to accept partial or total OS boot failure is stated

If ANY box is unchecked: **Phase 6 MUST NOT begin.**

## What Phase 6 is (and is not)

- Phase 6 is about OS interaction, expectations, and higher-level bring-up strategy.
- Phase 6 is not a continuation of Phase 5 hardware bring-up.

## Non-negotiable boundary

After Phase 5, hardware contracts are sealed. Any further hardware work requires a NEW phase definition with explicit scope and acceptance criteria.
